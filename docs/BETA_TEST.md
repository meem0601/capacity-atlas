# Capacity Atlas 第三者導入テスト

## 目的

開発者や既存利用者の補助なしで、初見の利用者が「ダウンロード → Connector起動 → AIアカウント接続 → 利用枠表示」まで完了できるかを確認します。機能評価より先に、導入時の離脱点を特定します。

## 対象者

- ChatGPT / Codex、Claude、Grokのうち2サービス以上を日常利用している人
- Capacity Atlasを使ったことがない人
- macOS（Apple Silicon）またはWindows x64の個人PCを使える人
- 最初の10分間、操作の助言なしで試せる人

まず5人で実施し、可能ならmacOS・Windowsを最低2人ずつ含めます。

## テスターへ渡すもの

1. 公開ページ: <https://capacity-atlas.vercel.app>
2. 「普段使うAIアカウントを1つ接続し、残容量が表示されるところまで進めてください」
3. 詰まった場合は、画面の「導入診断をコピー」で生成した内容だけを共有してもらいます

認証コード、メールアドレス、Cookie、トークン、実際の利用枠、エラー全文は回収しません。画面共有をする場合も、認証画面とアカウント情報は映さないでください。

## 観察手順

1. 開始時刻とOSだけを記録する
2. 最初の10分間は口を挟まず、迷った画面と操作だけを記録する
3. 次の到達時刻を記録する
   - 公開ページを開いた
   - OS版をダウンロードした
   - ZIPを展開した
   - Connectorを起動した
   - 「Connector接続済み」になった
   - OAuthを開始した
   - OAuthを完了した
   - ダッシュボードに利用枠が表示された
4. 10分経過後のみ、必要なら補助する
5. 翌日または7日以内に、もう一度自力で開けたか確認する

## 終了後の質問

1. 最も不安だった画面はどこでしたか
2. 次に何をすればよいか分からなかった箇所はありましたか
3. 表示された情報を、どんな場面で使えそうですか
4. メニューバー常駐や残量通知があれば毎週使いますか
5. もう一度使いたいですか。使わない場合、最大の理由は何ですか

## 合格条件

- 5人中4人以上が、補助なし・10分以内に利用枠表示まで完了
- macOSとWindowsの双方で少なくとも1件成功
- 認証情報の入力先について重大な誤解が0件
- 5人中3人以上が7日以内に再利用

未達の場合は、新機能を追加せず、最も手前で人数が落ちた工程から修正します。

## 計測値との照合

Vercel Web Analyticsの次のイベント件数を観察記録と照合します。

- `download_clicked`（OS、表示位置のみ）
- `connector_ready`
- `oauth_started`（サービス名のみ）
- `oauth_completed` / `oauth_failed`（サービス名のみ）
- `dashboard_ready`

アカウント名、メールアドレス、認証情報、残容量、リセット時刻、エラー本文はイベントに含めません。ブラウザのDo Not Trackが有効な場合、ローカル画面からのイベント送信は行いません。
